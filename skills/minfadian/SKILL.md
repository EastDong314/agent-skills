# 民法典条文查询

## 数据与版本

- 文本：2020-05-28 第十三届全国人民代表大会第三次会议通过，**2021-01-01 施行**；共 **1260 条、7 编、84 章**，另附则（第 1259–1260 条）。
- 民法典本体自施行以来**未经修正**；用户问「最新」时，指的是这一版本。
- **本 skill 不含**：司法解释、指导性案例、其他法律（如《民事诉讼法》）、地方性规定。这些必须另行核实，不要用这里的条文冒充。
- 法律、法规等具有立法性质的文件不受著作权法保护，全文可自由引用。

## 查询流程

**按条号查（最常用）**——注意正文用中文数字，用户通常说阿拉伯数字，先过速查表：

```bash
cd <本 skill 目录>
grep "^1042 " references/条号速查.md          # → 1042 | 第一千零四十二条 | 第五编 婚姻家庭 · 第一章 一般规定
grep -h "^第一千零四十二条 " references/第5编-婚姻家庭.md
```

**按主题查（不知道条号）**：

```bash
grep -n "居住权" references/*.md | head -20        # 先定位候选条文
grep -rn "离婚冷静期\|三十日" references/第5编-婚姻家庭.md
```

**需要上下文**（前后若干条、整节）时，用 read 工具只读目标行范围，例如 `read references/第5编-婚姻家庭.md offset=... limit=...`。

⚠️ **不要整篇读入文件**：全文约 9.6 万字符（约 6–9 万 tokens 量级），单编最大的第三编合同就有 13.8 万字节。始终先 grep 定位再切片阅读。

## 引用规范

- **逐字引用**，并标注「第 X 条」；保留原文的全角标点（`；`「、」）与分项结构（（一）（二）…）。
- 区分「条文原文」与「解读/适用意见」：解读要明确标出是解释，不得混在引文里。
- 条文的项、款按原文顺序呈现，不要合并改写。
- 本 skill 未覆盖的内容（司法解释、判例、其他法律）必须说明需要另行核实，不要凭印象补。
- 检索不到时要明说检索不到，不要编造条号或条文。

## 数据来源与校验（2026-09-21）

- **底本**：安徽省人民政府网转发的《中华人民共和国民法典（全文）》（新华社受权发布文本），全角标点正确。
- **交叉校验**：与贵州省人大、北京市人大两处官方全文按条逐条比对，**1260 条的汉字内容零差异**。
- **结构校验**：1260 条连续编号、无缺号无重复；7 编 + 附则；84 章 37 节；首条结尾与末条施行日期断言通过。
- **已知标点差异**：贵州人大那份把「；」渲染成半角「;」（211 处），因此未采用为底本。
- **重建方式**：`python3 scripts/build_minfadian.py`（默认从底本 URL 拉取并重建全部文件；`--dry-run` 只校验不写盘）。
